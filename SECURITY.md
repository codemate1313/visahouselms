# Security Policy

## Supported Versions

We actively support and patch the following versions of Visa House LMS:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it to us immediately to help keep the platform secure.

To report a vulnerability:
1. Email us at `security@visahouselms.com` with details of the vulnerability.
2. Please include description, steps to reproduce, and potential impact of the issue.
3. We will acknowledge your report within 48 hours and work on a prompt resolution.

Thank you for helping keep Visa House LMS secure!
